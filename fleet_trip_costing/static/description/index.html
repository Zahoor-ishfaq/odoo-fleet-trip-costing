Fleet Trip Costing & Profitability

Know which trips make money.

Per-trip cost capture, cost/km, and margin analytics on top of Odoo Fleet.

Trip costing

Log cost lines per trip against a configurable list of cost types — fuel, tolls, driver allowance, maintenance allocation, depreciation, and miscellaneous. Total cost is summed automatically as lines are added or removed.

Margin analysis

Revenue, total cost, cost per km, margin, and margin percentage are computed and stored on every trip — no exporting to a spreadsheet to find out whether a trip was worth running.

Fleet-wide analytics

Pivot and graph views break cost, revenue, and margin down by vehicle, driver, and month — built on Odoo's standard read_group reporting, no custom aggregation code.

Clear workflow

Trips move through draft, in progress, and done, with cancel and reset available where it makes sense. Every transition is guarded against invalid state changes.

Full Arabic support

A complete Arabic translation using formal transport and logistics terminology, with right-to-left layout throughout the interface.

What's included

✓ Trip records linked to vehicle, driver, and route
✓ Configurable cost types (fuel, tolls, allowance, maintenance, ...)
✓ Auto-computed distance, cost/km, margin, and margin %
✓ Draft → In Progress → Done workflow with cancel/reset
✓ Pivot and graph analytics by vehicle, driver, and month
✓ Multi-company aware, scoped by record rule
✓ Full Arabic (RTL) translation
